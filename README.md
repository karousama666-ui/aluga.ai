# 🏠 Aluga.ai Brasil

Agregador inteligente de imóveis para aluguer que utiliza **Processamento de Linguagem Natural (Gemini 2.5 Flash API)** e **Web Scraping em Tempo Real (Playwright)**.

## 🚀 Tecnologias Utilizadas
- **Backend:** Python, FastAPI, SQLAlchemy, Uvicorn
- **IA:** Google Gemini API (`google-genai` SDK)
- **Scraping:** Playwright
- **Frontend:** HTML5, Tailwind CSS, JavaScript Vanilla
